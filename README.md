## 👋 About Me

Hi there! I'm **Saybal Roy**, a passionate 💻 **Mern Stack Web Developer** and 🎓 **Computer Science student** at **Sylhet Engineering College**. I specialize in building scalable, user-centric web applications using the **MERN stack**, along with modern tools like **Firebase Authentication** and **TailwindCSS**.

I thrive on learning through building—and have recently completed two full-stack projects:

- 🔹 **SayMeets** – A full stack video calling platform where user host instant or scheduled meetings in a real-time.
- 🔹 **Biggan-Quiz** – A full-stack exam platform where admins schedule MCQ exams and students attempt them in a time-controlled environment.

My mission is to deliver clean, efficient code, performant systems, and intuitive user experiences in every project I build.
